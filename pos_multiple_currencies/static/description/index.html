Multi-Currency POS Payments

This Odoo Point of Sale module enables accepting payments in multiple currencies at the checkout. Perfect for businesses in tourist areas, border regions, or companies dealing with international customers who prefer to pay in their local currency.



Key Features
  • Multi-Currency Payments: Accept payments in various foreign currencies
  • Real-time Exchange Rates: Automatic currency conversion using current rates
  • Smart Currency Popup: Intuitive interface for selecting currency and entering amounts
  • Detailed Closing: Comprehensive breakdown by employee and currency in closing
  • Receipt Integration: Foreign currency amounts displayed on customer receipts
  • Flexible Configuration: Configure which currencies to accept per POS
  • Community and Enterprise Edition Compatible

Installation & Configuration

  1. Install the Module: Install through Odoo Apps or manually
  2. Configure POS: Go to Point of Sale → Configuration → Point of Sale
  3. Enable Multi-Currency: Check "Multi Currency" option in POS settings
  4. Select Currencies: Choose which currencies to accept in this POS
  5. Start Session: Open POS session multi-currency payments
  6. View closing: Check closing control for currency breakdowns
